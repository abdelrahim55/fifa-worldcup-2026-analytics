# Dashboard Video Walkthrough (3–5 minutes)

## 1. Overview — 0:00–0:30

Open **Overview** and briefly explain what the dashboard covers. Point to the main KPIs, then the goals vs xG chart.

Example wording:

> “This dashboard brings the World Cup analysis into one place. The top cards summarize the selected matches, while the charts below show scoring, xG and results.”

## 2. Filters — 0:30–0:55

Select one team, such as Egypt, and keep the date range broad. Point out that the charts and tables update with the filter.

## 3. Match Center — 0:55–1:45

Open one match and show the score, xG, shots, possession, corners and event timeline. Then scroll to the starting XI.

Example wording:

> “The final score is only one part of the match. Here I can compare chance quality, shot volume, possession and the match events.”

## 4. Teams — 1:45–2:20

Open **Teams Intelligence**. Show the table, FIFA rank, ELO and scoring output. Explain briefly what each measure is used for.

## 5. Players — 2:20–2:55

Open **Player Lab**. Show goals, assists, total contributions and the rate-based metrics.

Example wording:

> “I use both totals and rates here. That makes it easier to compare players who did not play the same number of matches or minutes.”

## 6. SQL Analytics Lab — 2:55–3:35

Open **SQL Analytics Lab** and run one query. Show the SQL and the result table. Mention that the database is rebuilt from the project data.

## 7. Data & Methodology — 3:35–4:15

Open **Data & Methodology** and show the flow:

`Raw data → Cleaning → EDA / Feature Engineering → Processed data → Dashboard`

Then point out where the SQL warehouse fits.

## 8. Closing

End on the Overview page and give a one-sentence summary of the project.

> “The project combines the original analysis notebooks, processed datasets, SQL queries and an interactive Streamlit dashboard.”

## Keep the video focused

- Use one team and one match for the demo.
- Show one SQL query rather than the whole SQL folder.
- Do not read every KPI.
- Keep the code in GitHub and spend the video on the dashboard and the results.
